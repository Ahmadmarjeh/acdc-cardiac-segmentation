# ACDC cardiac MRI segmentation and diagnosis

CMPS 261 final project by Ali Jomaa, Ahmad Marjeh and Omar Zabaneh.

We used MRI scans at two points in the heartbeat to outline the ventricular cavities and heart muscle. We then tested whether measurements from those outlines could help classify a patient into one of five ACDC diagnosis groups.

[Final notebook](notebooks/ACDC_Final_Project_Organized.ipynb) · [Final report](reports/CMPS261_ACDC_Final_Report_Revised.pdf) · [Result tables](results/) · [Model releases](https://github.com/Ahmadmarjeh/acdc-cardiac-segmentation/releases)

## Results

We selected settings using five patient-level folds on 100 development patients. We trained the final models on those 100 patients and evaluated them on a separate set of 50 patients.

| Task | Model | Five-fold validation | Held-out test |
| --- | --- | --- | --- |
| Segmentation, mean foreground Dice | Pixel-wise Random Forest | 0.3907 | 0.3689 |
| Segmentation, mean foreground Dice | 2D U-Net trained from scratch | 0.8264 | 0.8438 |
| Diagnosis, accuracy | Random Forest on six MRI slices | 37% | 46% (23/50) |
| Diagnosis, accuracy | CNN on six MRI slices | 27% | Validation only |
| Diagnosis, accuracy | U-Net measurements and logistic regression | 80% | 82% (41/50) |

The CSVs in `results/` reproduce the tables shown in the notebook at their displayed precision. In each test confusion matrix, rows give the true diagnosis and columns give the prediction. The earlier [progress report](reports/CMPS261_ACDC_Progress_Report.pdf) describes the initial single-split experiment.

## Run in Google Colab

1. Obtain the labelled training and testing data from the [ACDC dataset page](https://www.creatis.insa-lyon.fr/Challenge/acdc/databases.html). Place `training.zip` and `testing.zip` in the top level of Google My Drive. The paths inside each archive should start with `training/patient001/` or `testing/patient101/`, respectively. Keep the original `Info.cfg`, annotated MRI frames and matching `_gt.nii.gz` masks.
2. Open the [notebook](notebooks/ACDC_Final_Project_Organized.ipynb) in Colab and choose a GPU runtime. The notebook mounts Drive and installs NiBabel. The other Python packages it imports are listed in [requirements.txt](requirements.txt).
3. Run the cells from top to bottom in one session. Section 1 prepares the images and assigns folds. Sections 2 and 3 train and compare candidates. Section 4 selects, fits, saves and evaluates the final models. Section 4.4 uses the fitted models from 4.2 and the test arrays from 4.3.
4. Find the full-precision output CSVs generated by the notebook and the four fitted model files in `My Drive/ACDC_Project/results/organized_cv/`.

## Trained model files

The [releases page](https://github.com/Ahmadmarjeh/acdc-cardiac-segmentation/releases) is the download location for the trained models. Section 4.2 also regenerates them.

| Filename | Purpose |
| --- | --- |
| `final_random_forest.joblib` | Assigns a heart structure or background to each pixel using six features. |
| `final_unet.pt` | Stores the trained weights for the notebook’s `SmallUNet` segmentation model. |
| `final_diagnosis_rf.joblib` | Predicts the diagnosis group from 1,536 downsampled MRI pixel values. |
| `final_unet_diagnosis_head.joblib` | Predicts the diagnosis group from eight measurements. Use together with `final_unet.pt`. |
